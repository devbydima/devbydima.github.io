Description

Whoa, What Changed? is a free, single-player memory game for Android and iOS that works offline. A scene is shown for a few seconds, disappears for a moment and comes back with one small change. You tap what is different. Sometimes nothing changed, and in boss rounds there are two changes.

There are five unique themes (Kitchen, Living room, Bedroom, School and Garden), a daily challenge, an endless mode and Switcheroo, an optional two-player mode on one phone. The game is available in eight languages and is made by devbydima.
